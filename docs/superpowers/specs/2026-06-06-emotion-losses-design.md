# Emotion Losses — Design Spec
**Date:** 2026-06-06
**Status:** Approved

## Summary

Add two numeric fields to the Daily Card emotion log (section 6) tracking losses caused by FOMO and fear. Aggregate weekly in a new section 1C of the Weekly Review.

## Data model

Two new optional fields on `DailyCard` in `prisma/schema.prisma`:

```prisma
fomoLoss  Float?
fearLoss  Float?
```

Migration: `prisma migrate dev --name add_emotion_losses`
Follow with: `prisma generate`

## Daily Card — Step7EmotionLog

Below the emotion table, above the "+ Dodaj emocję" button, add two labeled numeric inputs:

- **Label:** "Ile straciłeś przez FOMO?"
- **Label:** "Ile straciłeś przez strach?"
- Input type: `number`, step `0.01`, placeholder `—`
- Save: `onBlur` via existing `updateDailyCard` server action (same pattern as `processScore` in Step8AreaScores)
- Style: `font-size-tiny`, `color-muted` labels, consistent with surrounding UI

## Weekly Review — WeeklyStep1Stats (section 1C)

New section rendered after the existing "1b" (Lekcje dnia) block.

### WeeklyStats additions (`lib/weekly-stats.ts`)

```ts
fomoSum: number      // sum of fomoLoss across all cards in the week (nulls treated as 0)
fomoCount: number    // count of cards where fomoLoss is not null
fearSum: number
fearCount: number
```

Computed in `computeWeeklyStats` from the already-fetched `cards` array — no extra DB query needed.

### UI rendering

```
▌ 1C  STRATY EMOCJONALNE
      [BridgeIndicator: "z kart dziennych"]

FOMO:    -350  (4 dni)
Strach:  -200  (3 dni)
```

- `SectionHeader number="1C" title="STRATY EMOCJONALNE"`
- Section renders only when `fomoCount > 0 || fearCount > 0` (no empty block on weeks with no entries)
- All amounts rendered in `var(--color-text)` — no red/green coloring (data, not judgment)
- Format: numeric value as-is, `—` if count is 0
